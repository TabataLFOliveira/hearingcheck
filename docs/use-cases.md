Caso de uso: Iniciar o HearingCheck

Ator: Usuário

Objetivo:
Acessar o HearingCheck e iniciar o processo de pré-triagem auditiva.

Fluxo principal:
1. Usuário acessa o HearingCheck através do link disponível.
2. Sistema apresenta a opção "Faça um teste rápido de percepção auditiva".
3. Usuário seleciona "Conheça o teste".
4. Sistema apresenta informações sobre a finalidade do teste e informa que ele é apenas uma pré-triagem e não substitui uma avaliação profissional.
5. Sistema apresenta o termo de consentimento.
6. Usuário aceita os dois termos.
7. Sistema pede nome e WhatsApp.
8. Sistema registra o contato e abre a primeira pergunta.

Caso de uso: Realizar questionário

Ator: Usuário

Objetivo:
Responder às 10 perguntas pontuadas e à pergunta sobre audiometria para obter uma classificação de pré-triagem.

Fluxo principal:
1. Usuário aceita os termos e informa nome e WhatsApp.
2. Sistema registra o pedido de contato e apresenta a primeira pergunta e a barra de progresso.
3. Usuário seleciona uma resposta.
4. Sistema registra a resposta.
5. Sistema atualiza a barra de progresso.
6. Sistema apresenta a próxima pergunta.
7. O processo continua até a pergunta sobre audiometria, que não entra na pontuação.
8. Sistema calcula a pontuação só com as 10 primeiras respostas.
9. Sistema determina a classificação.
10. Sistema apresenta o resultado, sem mostrar a pontuação.
11. Sistema confirma que a equipe poderá entrar em contato.
