Caso de uso: Iniciar o HearingCheck

Ator: Usuário

Objetivo:
Acessar o HearingCheck e iniciar o processo de pré-triagem auditiva.

Fluxo principal:
1. Usuário acessa o HearingCheck através do link disponível.
2. Sistema apresenta a opção "Faça um teste rápido de percepção auditiva".
3. Usuário seleciona "Conheça o teste".
4. Sistema apresenta informações sobre a finalidade do teste e informa que ele é apenas uma pré-triagem e não substitui uma avaliação profissional.
5. Sistema apresenta o termo de consentimento.
6. Usuário aceita o termo.
7. Sistema registra o aceite.
8. Sistema disponibiliza o início do questionário.

Caso de uso: Realizar questionário

Ator: Usuário

Objetivo:
Responder às 10 perguntas para obter uma classificação de pré-triagem.

Fluxo principal:
1. Usuário inicia o questionário.
2. Sistema apresenta a primeira pergunta e a barra de progresso.
3. Usuário seleciona uma resposta.
4. Sistema registra a resposta.
5. Sistema atualiza a barra de progresso.
6. Sistema apresenta a próxima pergunta.
7. O processo continua até a décima pergunta.
8. Sistema calcula a pontuação.
9. Sistema determina a classificação.
10. Sistema apresenta o resultado.

11. Caso de uso: Solicitar avaliação

Ator: Usuário

Objetivo:
Solicitar contato da clínica para uma avaliação auditiva após visualizar o resultado da pré-triagem.

Fluxo principal:
1. Sistema apresenta o resultado e a classificação.
2. Sistema apresenta a opção "Gostaria de receber uma avaliação auditiva gratuita com especialista?"
3. Usuário escolhe se deseja solicitar contato.
4. Caso o usuário não queira solicitar contato, o sistema apresenta uma mensagem de encerramento.
5. Caso o usuário queira solicitar contato, o sistema apresenta os campos para nome e telefone.
6. Usuário informa seus dados.
7. Sistema registra as informações fornecidas.
8. Sistema apresenta a mensagem "Obrigado! Nossa equipe entrará em contato."
9. Sistema encerra o fluxo.
