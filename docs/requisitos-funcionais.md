# Requisitos Funcionais

RF01 - O sistema deve permitir acesso ao HearingCheck por diferentes canais, como site, link em redes sociais e totem físico.

RF02 - O sistema deve apresentar informações sobre a finalidade do teste antes do início do questionário.

RF03 - O sistema deve solicitar o aceite dos termos e consentimento LGPD.

RF04 - O sistema deve apresentar um questionário composto por 10 perguntas.

RF05 - O sistema deve exibir uma barra de progresso durante o preenchimento.

RF06 - O sistema deve registrar as respostas do usuário.

RF07 - O sistema deve calcular automaticamente a pontuação final.

RF08 - O sistema deve classificar o resultado em níveis de atenção.

RF09 - O sistema deve apresentar orientações de acordo com o resultado obtido.

RF10 - O sistema deve oferecer ao usuário a opção de solicitar contato para uma avaliação especializada.

RF11 - O sistema deve permitir o cadastro de nome e telefone.

RF12 - O sistema deve exibir mensagem de confirmação após o envio dos dados.

RF13 - O sistema deve armazenar os dados cadastrados para posterior contato da equipe.
